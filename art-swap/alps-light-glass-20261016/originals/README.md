# Word Tile · 模拟试玩、原包反跑与 Zen 关卡编辑器 V8

## 新增工作区（2026-10-15 更新）

全宽工作台参考 P2 布局。词长按本关全部实际长度逐项统计，目标词与额外词分别列出，并提供各词长占比及全部目标词长的约分比。结构指标包含参考路径拐弯、反向、重复格子和最大使用次数；点击棋盘上方“开始试玩”后，本局指标统计错误、耗时、提示与实际连接操作；开始前与重开后耗时为0。Zen 自由字母池的空间指标显示不适用。

本地启动后进入游戏，编辑器顶部可切换“编辑关卡／模拟试玩／反跑关卡”。手机点击齿轮打开编辑器。新增功能在本地已实装，线上旧版本需发布后才会更新。

- **模拟试玩**：自己试玩并记录、普通英语玩家机器模拟、全知规则校验。普通模式只看可见字母和剩余次数，使用有限词汇记忆和搜索预算，允许试错、额外词、提示、超时与放弃。机器直接计算，用虚拟时间估算耗时；完成后弹窗进入下一关。机器不写入真人记录、不增加个人词典。
- **英语水平**：使用 wordfreq 3.1.1 的英语 Zipf 词频作熟悉度先验，参考真实玩家评论与认知研究确定行为。默认参数尚未获得海外玩家样本验证，导出保留 prior 状态。可合并至少10名普通英语玩家、30局有效记录，按测试者等权校准时间和失误率；词汇和观察参数仍保留先验。方法与许可见 `dist/playtest/methodology.html`。其他语言只做规则跑关。
- **棋盘规格**：右侧宽高区域可手动设为2～6列/行；目标词长可以自动推荐或手工填写。批量弹窗可多选规格，关闭难度曲线时使用当前宽高和词长。WT 原包载入时使用原始宽高；Zen 按原始字母池自动适配。
- **批量编排**：“配置批量生成”打开完整弹窗，分别设置起始关号、生成关数（1～10,000）、插入当前关之前/之后或追加末尾。目标词数可固定，也可从起点到终点渐变（1～16）。可选独立的网页、WT、Zen 词库及算法，选择多种棋盘尺寸、每格1～9次上限、难度起止、爬升关数、峰值间隔与回落幅度，并实时预览曲线。原网页 V1 保持3×3、5个目标、3/3/3/4/5词长和每格最多3次。
- **难度与校验**：曲线实际影响目标数量、词长、英语Zipf下限与路径拐弯上限；默认优先3～4字，覆盖棋盘时会调整词长。高级设置可改词长范围、词频门槛、低频词上限与相邻关避重范围。难度值是出题配置指标，尚不代表经过真人校准的海外玩家难度。每关使用新的系统随机值，重搜所有目标路径并检查全部完成状态；无法通过则重试，预算耗尽明确保留部分结果。
- **生成关序与手改**：新关卡按选定位置插入对应词库的关序，后续关号顺延。通关后按该关序进入下一关。点击列表“编辑”可改字母、目标词与路径，使用次数自动重算，完整校验通过才保存。关序及修改保存在本机浏览器，可导入/导出关序或整批JSON；导出当前词库关序时词库仅保存一次。完成时若当前关尚未开始且未切换，自动预览本批首关。浏览器禁用存储时可导出保留。
- **词库隔离**：网页来自用户原始 words.tsv（21,094词，原表实际3～8字）；WT 只使用安装包原目标与额外名单；Zen 使用T1/T3原目标与额外角色。目标、额外词、历史关卡、真人收词及导出均标明来源，跨来源拼写不会自动合并。统计完整列出2～10字，零数量也显示；存在更长的实际词时继续追加。目标占比 = 该词长的实际目标数 ÷ 本关总目标词数。
- **菜单**：“更多设置”只保留棋盘与目标、词库与频率档位。
- **反跑关卡**：从 Zen、Word Tiles 原包、网页生成关卡中选择来源、列表、起止序号、每关局数和模式；后台 Worker 运行，取消保留已处理结果。Excel 是真实 `.xlsx`，包含分析总览、逐关、逐局明细，可选词汇明细；无逐步操作导出。每个新网页关卡与每局模拟使用系统随机值。通关率95% Wilson 区间只反映模拟抽样误差，未处理关卡与错误不冒充失败局。
- **Zen 原包**：读取用户原 `Zen Word - v2.44.0.apk`，SHA-256 为 `6d5678c333fbe74bad85f3d63de46cdcdb1360e480afccef64fbc6d303957770`。页面只开放主线 T1、T3，各1,000关。全部20个英文资源组、7,773个原始位置保存在数据归档中。附带其他语言本地数据也保存，西班牙问答资源尚未解码，详情在目录 `unparsed`；远程关卡不在用户安装包内。
- **Zen 词库**：算法2“生成词库”可选择 Zen 原目标名单，并选择 T1、T3 或两者合并。仅 answer 可作为目标，其他角色不自动升级。生成器按配置的2～6列、2～6行及2～10字目标重新铺关，原Zen关卡从页面顶部选择来源后按原字母池试玩。保留2字母词、重复字母、完整原字段与角色；不替换原词频档位，不捏造缺失释义。

数据构建器：`scripts/extract-zen-levels.py` 从原APK直接读取全部本地关卡 TextAsset，每个二进制文件校验完整消费；`scripts/build-playtest-data.py` 建立独立的英语词频表。词频表是 CC BY-SA 4.0 派生数据，署名与来源保存在模型说明页。所需解析／词频 Python 包在原分析 vendor 与本次项目临时目录，运行网页不需要 Python。

## 算法与玩法

原XAPK的13,216个不同关卡与五语言完整开放，主线重复位置及顺序保留；目标和额外词沿用每关原列表，不做内容删关。原包行从下往上存储，网页按手机方向展示；参考消耗集合固定、次数反算，同集合其他合法路径仍可完成。见 [原包棋盘行方向核查](reports/原包棋盘行方向核查.md)。所有原包目标关均完成正序／反序实际会话验收；额外词支持非ASCII与超过8字母的原拼写。

算法2使用用户原始 `src/wordtiles-algorithm.ts`，版本 `backtrack-v1.0.0`，未改源码。固定3×3、5个不同目标，长度3/3/3/4/5，每格1～3次。长词优先铺设、回溯、反算次数、唯一消耗集合及全部32种完成状态校验。默认预算10,000节点/尝试、30尝试、总300,000节点；预算代表搜索量。

拖动连接上下左右相邻格子，不重复经过同格，松手才提交。正确目标相关次数减1；归零留空，棋盘不移动。有效额外词只入单词包和词典，不扣次数；未知词相关格子变红。提示使用方向箭头。全部目标可按任意顺序完成。重开保留词典，清空本关额外单词包；切算法保留各自进度。

当前默认seed20261010为ATE、END、SAT、SEEK、ASIDE，与 `examples/tsv/seed_20261010.json` 逐字段一致。seed6为ILL、LID、SIX、DILL、SIXTH，用来验证拖动经过SIX不会提前提交SIXTH，保存在 `examples/tsv/prefix-regression.json`。此前TSV样例保留在 `examples/history/tsv-v1-seed_20261010.json`；旧版本关卡仍须检查词库和路径次数，不能直接替换版本绕过规则。

编辑器统计保持现有口径：非目标词按本关完整有效额外词库去重；倒序只看起终点，终点在左侧或上方计入；目标格子使用次数和直线/1拐/多拐只按目标参考路径统计。解法统计候选仍是当前合法目标库，同一词组只计一次，预算未完成时不冒充精确总数。

算法2保留原平铺V1 JSON及内部渲染适配，导出只含完整初始关卡。生成成功后仍须通过原校验器和独立Demo DFS校验；违规目标整关拒绝。
