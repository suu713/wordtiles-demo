## 算法与玩法

原XAPK的13,216个不同关卡与五语言完整开放，主线重复位置及顺序保留；目标和额外词沿用每关原列表，不做内容删关。原包行从下往上存储，网页按手机方向展示；参考消耗集合固定、次数反算，同集合其他合法路径仍可完成。见 [原包棋盘行方向核查](reports/原包棋盘行方向核查.md)。所有原包目标关均完成正序／反序实际会话验收；额外词支持非ASCII与超过8字母的原拼写。

算法2使用用户原始 `src/wordtiles-algorithm.ts`，版本 `backtrack-v1.0.0`，未改源码。固定3×3、5个不同目标，长度3/3/3/4/5，每格1～3次。长词优先铺设、回溯、反算次数、唯一消耗集合及全部32种完成状态校验。默认预算10,000节点/尝试、30尝试、总300,000节点；预算代表搜索量。

拖动连接上下左右相邻格子，不重复经过同格，松手才提交。正确目标相关次数减1；归零留空，棋盘不移动。有效额外词只入单词包和词典，不扣次数；未知词相关格子变红。提示使用方向箭头。全部目标可按任意顺序完成。重开保留词典，清空本关额外单词包；切算法保留各自进度。

当前默认seed20261010为ATE、END、SAT、SEEK、ASIDE，与 `examples/tsv/seed_20261010.json` 逐字段一致。seed6为ILL、LID、SIX、DILL、SIXTH，用来验证拖动经过SIX不会提前提交SIXTH，保存在 `examples/tsv/prefix-regression.json`。此前TSV样例保留在 `examples/history/tsv-v1-seed_20261010.json`；旧版本关卡仍须检查词库和路径次数，不能直接替换版本绕过规则。

编辑器统计保持现有口径：非目标词按本关完整有效额外词库去重；倒序只看起终点，终点在左侧或上方计入；目标格子使用次数和直线/1拐/多拐只按目标参考路径统计。解法统计候选仍是当前合法目标库，同一词组只计一次，预算未完成时不冒充精确总数。

算法2保留原平铺V1 JSON及内部渲染适配，导出只含完整初始关卡。生成成功后仍须通过原校验器和独立Demo DFS校验；违规目标整关拒绝。
