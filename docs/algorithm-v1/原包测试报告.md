# Word Tiles V1 算法实测报告

## 测试范围

测试对象：`wordtiles-algorithm.ts` 编译出的 `dist/wordtiles-algorithm.js`。算法版本 `backtrack-v1.0.0`。没有加载或修改用户 Demo 源码，没有进行用户 Demo 的浏览器操作、动画、手机或 Web Worker 消息链路验收。

环境：Node.js `v22.16.0`，linux / x64，处理器 AMD EPYC 9V74 80-Core Processor。这些是本次计算环境，不是用户设备性能指标。

词库 `demo-test-20261010-v1`，共 1602 个候选词。它是测试集合，不是经过产品审核的生产词库。

## 参数

固定 3×3、5个不重复目标、词长3/3/3/4/5、每格1～3次。每次尝试最多10,000节点，最多30次尝试，总预算300,000节点。测试 seed 从0到999，没有跳过失败seed，没有更换词库，没有自动载入固定样例。

去重定义：包含目标单词集合、棋盘字母和逐格次数；镜像/旋转等价按正方形八种对称变换归并。有序参考路径的书写方向不构成不同关卡。不同目标组合即使共用某个字母布局，也视为不同关卡。

独立检查器不导入生成器或它的找路函数。它先枚举3×3上的全部合法几何路径，再按字母与次数筛选，检查每个目标唯一消耗集合；对每关完整检查32种已完成集合，并回放120种目标完成顺序。这里回放的是参考逻辑，不是用户 Demo 的实际提交函数。

## 计算时间与节点数

测量只包围同步 `generateLevel` 调用，含该调用的词库预处理、搜索与32状态终检；不包括模块加载、文件读写、Worker启动、UI渲染和额外独立测试。

| 指标 | 单关生成时间（毫秒） | 搜索节点 |
|---|---:|---:|
| 平均 | 0.696 | 16816.7 |
| 中位数 | 0.577 | 13354 |
| P95 | 1.467 | 48066 |
| 最大 | 5.090 | 142885 |

最大尝试次数为 15，低于本次上限30。时间会受硬件、运行时、热身和系统负载影响，不代表所有输入或手机端的耗时。

## 已覆盖的失败与边界

33项测试包含：EYE同集合多方向合法、同目标不同消耗集合非法、前缀词FEE/FEED、禁止跳空位和同词复用格子、正确邻接、逐格次数错配、重复目标或id、异常JSON、非法参考路径、缺少白名单词、规范化与去重、种子复现、极小预算、单次上限、取消、输入不被修改、导入导出、仅五个样例词生成、终检中断不输出半成品，以及完整搜索耗尽与有限预算失败的区分。

## 限制与结论

在本次固定词库、预算和0～999这些seed上，生成和独立检查全部通过。**不是对任意词库、任意seed、任意预算100%成功的保证**。修改词库、规则或预算应重新测试。

输出满足玩法约束，不等于词语适合目标受众，也不等于关卡难度均衡、时长达标或内容足够有趣。当前没有词频分层、难度模型或关卡之间的在线去重记忆。

可以将这版算法接入现有Demo做第一轮真实操作体验。界面层仍需验证点击/拖动、松手、动画、重复事件、重开、切关和Worker取消。

逐seed记录见 `benchmark-results.json`，完整测试案例见 `unit-test-results.json`。
