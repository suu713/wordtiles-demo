# Word Tiles｜替换为常用原形词白名单 V2

## 目标

现有界面和玩法保持不变。修复“算法2会用 NAT、TEL、DELL、RATED 等不合适词出题”的问题。正式目标词改用随包完成筛选的白名单。禁止再要求用户逐词审核。

本次政策：普通常见独立词条为主；不使用复数、第三人称单数、过去式、分词、比较级等纯语法变形；不使用缩写片段、专名主导词、罕见词义凑答案。TEACHER、FLOWER、PUDDING、CEILING 等独立词条不能按后缀误删。CUT、PUT、HIT、READ 本身也是原形，允许。SAW、ROSE 等明显的过去式同形词本版保守停用，不表示它们不是英语词。

## 正式数据与来源

- `dictionary.json`：完整白名单，3333词；没有3～5字母限制。本次收录长度1～15，不代表今后词长上限是15。
- `dictionary_3to5.json`：1471词，仅为旧3×3 V1生成器提供的兼容视图；不是新母库。
- `whitelist.mjs`：不依赖外部包的准确词条门禁、按词长取子库、关卡目标词检查。
- `apply_whitelist.py`：给先前分级构建器的 `{metadata,entries}` 母库应用本次白名单，保留词频、分档、来源和授权说明；不联网、不重新评分。
- `audit/`：诊断、筛选记录和重建材料。不得把这些文件中的被拒绝词、候选词当作另一份可生成词库。
- `tests/`：历史原算法的参考测试；不是替换你现有算法2的要求。

## 必须接入

1. 先阅读项目实际的词库加载器、算法1/算法2、候选索引、生成Worker、导入器、关卡缓存和样例入口。不要重写UI或更改棋盘、目标长度、次数、连接规则。
2. 备份旧运行词库；生成正式关卡只用 `dictionary.json` 的精确集合。不得与旧1602词库/原始大母库做并集。删除或禁用“放行未审核词”的生成绕过路径；词不足或搜索失败时直接报错，不回退到未筛选词库。
3. 词长只在运行时按现有关卡配置过滤。现有V1可直接使用 `dictionary_3to5.json`；以后6/7/8等长度必须从完整 `dictionary.json` 筛，不要把母库永久截断。
4. 所有生成策略和关卡导入必须使用同一内容政策。每次生成后，先检查每一个target.word在白名单，再通过原路径/次数/完成状态校验。不允许只在UI上隐藏违规词。
5. 玩家提交不做自动词形还原：RATED不能当成RATE成功，APPLES不能当成APPLE成功。也不要把生成结果中RATED改成RATE而保留原棋盘路径和次数；存在违规目标的关卡应整关拒绝/重新生成。
6. 词库版本键更新为 `wordtiles-common-base-20261010-v2`（兼容子库为 `...-len3to5`）。候选索引、预生成关卡、Worker内存、相关localStorage/service-worker资源缓存必须按新版本失效；不要清空用户其他设置或无关进度。当前已加载旧关需重新生成，不能继续从旧缓存出题。
7. 旧固定样例包含LAD，旧seed20261010包含OAT，本版白名单均不再放行。保留历史测试文件作归档，但正式界面的默认样例换成随包 `examples/seed_20261010.json` 或新生成的合格样例。不要为通过旧样例把LAD/OAT加回去。
8. 如果项目现在使用分档母库，运行：

   ```bash
   python apply_whitelist.py --master "实际路径/dictionary.master.json" --out "实际路径/lexicon-clean-v2"
   ```

   输入是先前构建器的真实母库，输出目录必须是新目录。以 `dictionary.master.reviewed.json` 作为带词频元数据的版本，或以 `dictionary.runtime.json` 作为生成接口。`targetEnabled=false`/`reviewStatus=blocked` 项绝不能用于出题。现有明确blocked项会继续保持禁用。

   运行时候选 = 当前词长/频率条件 ∩ 本次白名单 ∩ 未被项目明确禁用。不得把未知词频补为“非常常用”，不得伪造Zipf分数。输出会有新版五个分档及未评级文件，其值沿用原母库，不重新估算。
9. 替换后显示真实版本和可用词数，例如“常用原形词 V2”。不要只删掉“词库未完成内容审核”提示而不改变词的来源；不要标注“母语用户100%认识”。
10. 运行随包门禁/应用测试，然后在**当前实际算法2**重新跑至少100个seed，记录成功/失败、目标词、词库版本。包内1000seed结果只针对此前给出的原V1算法，不是你当前修改版的验收结果。

## 关键回归断言

- NAT、TEL、DELL、RATED、APPLES、CATS、WENT、RUNNING、WOMEN、FEET、HAPPIER都不能作为目标。
- AND、RATE、APPLE、CAT、GO、RUN、WOMAN、FOOT、HAPPY仍允许；实际能否用于当前关卡受现有词长限制。
- BUS、GLASS、KING、TEACHER、FLOWER、PUDDING、CEILING、CUT、PUT、READ不能因为后缀/过去时同形而误删。
- 任何策略、导入、旧缓存都不能绕过白名单。
- 生成失败明确返回，不偷偷放宽词的内容限制。
- 原有松手提交、前缀词、共享次数、任意完成顺序与归零不移动保持不变。
