# 常用原形词白名单 V2

## 可直接使用的成品

`dictionary.json` 是3333个已选定词条的运行白名单，接口保持 `{version, words}`。
这不是仅给筛选规则或要求用户继续审批的工具包。原1602词已逐条做保留/剔除决策，并补充常见长词，形成可立即替换的有限答案池。

| 项目 | 数量 |
|---|---:|
| 原提供词库 | 1602 |
| 原词库保留 | 1436 |
| 原词库剔除 | 166 |
| 新增选定基本词条 | 1897 |
| 全词长白名单 | 3333 |
| 其中3～5字母，供旧Demo使用 | 1471 |
| 超过5字母 | 1841 |
| 1～2字母 | 21 |

母白名单不按3～5字母截断。本次条目长度1～15，这是所选词条的分布，不是未来生成器的固定长度上限。`dictionary_3to5.json`只是当前V1接口的兼容视图。

## 本次实际处理范围

能够读取到的是此前交付的原1602词库、生成器和分级构建工具。用户在本机运行构建器后得到的扩展母词库并未出现在本次可访问文件中。因此本包**不是对那份本机全母库逐条处理后的完整导出**，也不虚报它的删除数量。

解决方法是把本包作为精确的正式目标白名单。原始母库可以保留词频与其他元数据，但运行候选必须与白名单求交集；白名单外一律不能出题。`apply_whitelist.py`可无联网地完成该交集与标记，保留原词频分档和许可材料。它的输入适配按此前工具实际输出的 `{metadata,entries}` 编写，已做合成样例测试，没有在用户尚未提供的实际母库上运行。

## 筛选政策

删除语法变形：名词复数、第三人称单数、过去式、过去分词/现在分词、比较级和最高级，包括不规则变形。比如 RATED、PLAYED、RUNNING、WOMEN、FEET、BETTER。本版还保守停用SAW、ROSE、LEFT等过去式同形词，这不是宣称它们没有普通词义。

删除或停用缩写片段、专名主导词、低熟悉度短词和容易让人觉得“凑词”的条目。NAT、TEL、DELL明确不在新白名单。个别本身正确的普通词也可能为降低理解成本被停用；停用不等于拼写错误。

不按末尾字母一刀切。BUS、GLASS不是本任务要排除的复数；KING不是动词分词；TEACHER、FLOWER、BUSINESS等是独立词条；PUDDING、CEILING、MORNING、EVENING等以常见独立名词处理。CUT、PUT、HIT、READ本身就是可用原形，不因同形过去式而删除。常见词构成的普通衍生词和合成词不全部删除，用户要求的是消除语法变化，不是只剩词根。

原词库中被删的166项及其理由见 `audit/removed_original_1602.json`；1602项逐词决策见 `audit/original_1602_decisions.json`。新增候选经过同一显式排除表，实际准入只以根目录 `dictionary.json` 为准，不能直接用audit候选列表。

## 词频与体验的界限

本次筛选是保守的产品内容决策，不是测量出来的五档Zipf评分。没有给新增词伪造词频、CEFR级别或母语者认识率。旧母库已有的zipf/frequencyTier/frequencyLabel由应用脚本原样保留；不把“没有分数”改成“非常常用”。

这份白名单旨在明显减少缩写、变形和冷词造成的停顿，但没有针对目标年龄群做母语玩家实测，不能承诺每个母语者认识每个词，或每个关卡没有找词停顿。关卡布局难度也不由词表一项决定。

## 核验与复现

`tests/test-gate.mjs`：22项白名单门禁/边界测试。
`tests/test_apply.py`：13项旧母库接口的合成数据测试。
`tests/benchmark.mjs`：使用此前交付的未修改V1参考生成器，seed 0～999，1000/1000成功；每关32种完成状态和120种参考消除顺序全通过。所有目标均在白名单，相同seed重跑结果一致。不是用户当前算法2、UI、动画或缓存测试。

```bash
node tests/test-gate.mjs
python tests/test_apply.py
node tests/benchmark.mjs 1000
```

新词库的seed结果应按新样例验证，不要求重现旧词库布局。新seed20261010的五个目标是LOW、OWN、WHO、WHEN、HELLO。旧默认样例LAD和旧样例OAT已停用，不得为了复现旧关把它们放回白名单。

## 文件使用

先将整个目录交给Codex，按 `交给Codex的替换指令.md` 接入。所有生成算法和导入都应用门禁；不得将新词库与旧母库并集合并。需要继承已构建的频率等级时运行 `apply_whitelist.py`，输出新目录不会修改原始文件。
