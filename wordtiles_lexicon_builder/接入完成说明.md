# 历史扩库工具与当前TSV入口

本目录保留此前接入的真实母库构建源码、锁定依赖、原始输出和许可信息，用于追溯旧词频数据。此前143,581词母库及V2交集的实际验收见 reports/扩展词库接入验收.md 与 reports/常用原形词V2接入验收.md。

当前Demo已按用户后续要求改用 words.tsv，不再加载原候选索引或旧Zipf母库，不再提供“允许未审核词”入口。新TSV逐字节归档在 data/words.tsv，使用 npm run package:words 打包；原TSV的1～5档与中文释义保留，目标仍与原形成品白名单取交集。

旧lexicon-output原始母库保留。过时的lexicon-clean-v2输出和临时虚拟环境已经清理；它们不再是当前Demo依赖。当前有效测试与源文件说明见项目根README.md和 reports/大厅词典与TSV接入验收.md。
